# Аналитика образовательных курсов

## 📌 Обзор
Данный проект представляет собой комплексный анализ данных об образовательных курсах. Основная цель — подготовить аналитический отчёт для продюсеров образовательных программ. Анализ включает в себя изучение структуры курсов, портрета аудитории, расчёт нагрузки на преподавателей и выявление проблемных модулей.

## 🎯 Основные задачи
- Изучить структуру курсов и портрет студентов.
- Рассчитать потенциальную нагрузку на преподавателей.
- Проанализировать качество контента и выявить проблемные модули.
- Разработать метрику успеваемости студентов.

## 📁 Данные
В проекте используются следующие датасеты:
- `courses.csv` — информация о курсах (ID, название, сфера).
- `students.csv` — данные о студентах (ID, город, дата рождения).
- `course_contents.csv` — структура курсов (модули, уроки, наличие видео/ДЗ).
- `progresses.csv` — прогресс студентов по курсам.
- `progress_phases.csv` — детали прогресса (статус, даты начала и завершения).

## 🛠️ Используемые технологии
- **Pandas** — обработка и анализ данных.
- **Matplotlib** и **Seaborn** — визуализация данных.
- **NumPy** — математические вычисления.
- **Datetime** — работа с датами.

## 📊 Основные этапы анализа

### 1. Описание и начальная работа с данными
- Объединение датасетов в общую таблицу.
- Расчёт ключевых метрик:
  - Количество курсов, модулей и уроков.
  - Статистика по возрасту студентов (мин, макс, среднее, медиана).
- Построение bar-charts для визуализации количества студентов на курсах.

### 2. Расчёт нагрузки на преподавателей
- Определение количества студентов, начавших первую домашнюю работу по месяцам.
- Построение line-graphs для визуализации прироста студентов.
- Расчёт количества прогрессов по выполнению ДЗ в разрезе месяцев и курсов.

### 3. Анализ качества контента
- Выявление проблемных модулей на основе статистики прохождения уроков.
- Расчёт конверсии между этапами обучения.

### 4. Разработка метрики успеваемости
- Создание пользовательской метрики для выявления студентов, значительно отстающих от общего темпа обучения.

## 📈 Ключевые выводы
- **Структура портфеля:** Направление «Разработка» представлено наибольшим числом курсов (6), однако наибольшее количество студентов сосредоточено в сферах «Дизайн» и «Маркетинг».
- **Популярность курсов:** Самый популярный курс — «Интернет-маркетолог от Ingate» (2168 студентов), наименее популярный — «SMM-маркетолог от А до Я» (506 студентов).
- **Портрет студента:** Средний возраст студентов — 34 года. Самый молодой в среднем возраст у слушателей курсов по веб-дизайну и разработке (33 года), самый взрослый — у слушателей «Excel Базовый» (39 лет).
- **Нагрузка на преподавателей:** Наибольший прирост студентов и количество проверок ДЗ приходятся на период с конца 2018 по начало 2019 года, что может указывать на сезонность или успешные маркетинговые кампании.
- **Качество контента:** Выявлены модули с низкой конверсией, которые требуют доработки для повышения вовлечённости студентов.

## 🚀 Как использовать
1. Убедитесь, что все необходимые CSV-файлы находятся в одной директории с ноутбуком.
2. Откройте `Coursework_analytics_1.ipynb` в Jupyter Notebook или JupyterLab.
3. Последовательно выполняйте ячейки для воспроизведения анализа.
