# HR-аналитика: Исследование данных о сотрудниках

Этот проект представляет собой комплексный анализ базы данных отдела кадров вымышленной компании. Основная цель — подготовить аналитический отчет и дать рекомендации по стратегии набора персонала и взаимодействию с текущими сотрудниками.

## 🚀 Основные задачи

1.  **Анализ штата сотрудников:** Изучить демографические, профессиональные и финансовые характеристики сотрудников.
2.  **Выявление зависимостей:** Проверить гипотезы о влиянии различных факторов (источник найма, семейное положение, отдел, возраст) на производительность и лояльность.
3.  **Формулировка рекомендаций:** На основе полученных данных предложить конкретные шаги для HR-отдела.

## 📊 Используемые данные

Анализ проводился на основе базы данных `human_resources`, которая содержит четыре основные таблицы:

*   **`hr_dataset`**: Основная таблица с полной информацией о сотрудниках.
*   **`production_staff`**: Данные о производственном персонале.
*   **`recruiting_costs`**: Информация о затратах на привлечение персонала.
*   **`salary_grid`**: Данные о сетке зарплат.

Данные были предварительно обработаны и подготовлены для анализа с использованием SQL и Python (pandas).

## 🔍 Ключевые выводы анализа

### 1. Влияние источника найма на производительность
*   **Самые эффективные каналы:** Реферальные программы (`Employee Referral`) и "точечные" каналы (профессиональные сообщества, вузы, соцсети) привлекают наиболее качественных и лояльных сотрудников.
*   **Наименее эффективные каналы:** Массовые и безличные каналы, такие как баннерная реклама (`Website Banner Ads`) и поисковые системы (`Internet Search`), дают большой, но низкокачественный поток кандидатов.

### 2. Влияние семейного положения
*   Основу компании составляют **женатые/замужние и холостые** сотрудники.
*   Холостые сотрудники демонстрируют лучшее соотношение высокой и низкой производительности, что делает их ценным активом для развития.

### 3. Распределение по подразделениям
*   **"Зона риска"** по низкой производительности сконцентрирована в **отделе продаж (`Sales`)**. Это требует детального аудита процессов и системы мотивации в этом подразделении.

### 4. Возраст и лояльность
*   Наиболее лояльное и опытное ядро компании — сотрудники в возрасте **от 30 до 50 лет** со стажем работы **3-5.5 лет** (1000-2000 дней).

## 💡 Рекомендации для HR-отдела

### Стратегия набора персонала

**Приоритет 1: Развивать эффективные каналы**
*   **Программа рефералов:** Увеличить бонусы и активно продвигать ее внутри компании.
*   **Профессиональные сообщества и вузы:** Участвовать в конференциях, организовывать стажировки и мероприятия для студентов.
*   **Социальные сети:** Использовать LinkedIn для активного поиска, а также Facebook и Twitter для продвижения бренда работодателя.

**Приоритет 2: Сократить неэффективные каналы**
*   Прекратить или значительно сократить инвестиции в баннерную рекламу, наружную рекламу и агрегаторы вакансий типа Monster.com.
*   Оптимизировать SEO-рекрутинг через более точные описания вакансий.

### Работа с текущими сотрудниками

**Приоритет 1: Работа с отделом продаж**
*   Провести аудит KPI, процессов и системы мотивации.
*   Внедрить программу наставничества и дополнительного обучения.

**Приоритет 2: Удержание ключевых групп**
*   **Для сотрудников 30-50 лет:** Разработать программы долгосрочной мотивации (опционы, планирование карьеры).
*   **Для холостых сотрудников:** Использовать их как пример для подражания, привлекать к проектам с повышенной ответственностью и предлагать карьерный рост.
